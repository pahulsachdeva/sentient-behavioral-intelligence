# Roadmap

## Working foundation

The app includes interview search and JSON import, source excerpts, behavioral categories, follow-up timelines, and experiment plans. Syntax checks and automated regression tests run in CI. Evidence reviews include saved decisions, notes, status filters, and JSON export.

## Current direction

The case study follows a consumer AI assistant. It focuses on the steps between opening a chat, getting something useful, and returning for another task. The README and interviews now share that setting.

## Next pieces

- Host the app and inspect the desktop and mobile experience.
- Independently review the uncertainty regression cases and broaden phrase handling beyond direct negation.
- Evaluate reviewer agreement on an independently coded set of interviews.
- Connect interview questions to task completion and return-use events.
- Evaluate an optional model adapter against the same evidence requirements.

[Track the work in GitHub Issues](https://github.com/pahulsachdeva/sentient-behavioral-intelligence/issues).
