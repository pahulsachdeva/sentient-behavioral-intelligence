# Data choices

I built the consumer AI assistant interviews for this project so I could explore the idea without using my company's internal examples. The names, interviews, and follow-ups belong to this case study. EliseAI is the context for my interest in the problem; this is my independent project.

Imports and reviewer decisions stay in the browser's local storage. Saved reviews include the source text used to identify the evidence, the decision, note, and save time. Evidence Explorer exports only current reviewed findings with their source excerpts. Clear all saved reviews from Research Workspace; clearing imports also removes reviews belonging to those records. Research Workspace includes a control to clear them. Use examples you have permission to work with, and avoid storing confidential transcripts on a shared device.

The source excerpt stays beside each interpretation so a reviewer can check the reading, consider another explanation, and decide what to ask next.
